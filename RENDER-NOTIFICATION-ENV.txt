LilianTech production notification environment variables

RESEND_API_KEY=<YOUR_RESEND_API_KEY>
NOTIFICATION_FROM=LilianTech <support@liliantech.online>
NOTIFICATION_EMAIL_ENABLED=true

NOTIFICATION_PUSH_ENABLED=true
VAPID_PUBLIC_KEY=<YOUR_VAPID_PUBLIC_KEY>
VAPID_PRIVATE_KEY=<YOUR_VAPID_PRIVATE_KEY>
VAPID_SUBJECT=mailto:notifications@liliantech.online

APP_BASE_URL=https://liliantech.online

IMPORTANT:
- Do NOT put SMTP_PASS or VAPID_PRIVATE_KEY in GitHub.
- Add them only to Render Environment Variables.
- Keep the same VAPID key pair permanently for existing browser subscriptions.
- Resend HTTP API is recommended for Render. Create/verify the liliantech.online sender domain in Resend, then add the API key to Render as RESEND_API_KEY. The server uses HTTPS instead of an SMTP socket, avoiding SMTP port connection timeouts.
